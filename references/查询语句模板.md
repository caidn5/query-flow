# 查询语句模板（第②步元数据 DMV · 第③步成员枚举 DAX 先查/MDX 兜底 · 出口组句执行）

> **何时读本文件**：执行 query-flow 第②步建底册、第③步成员层匹配、或出口组句执行时。全部语句照抄执行；占位符按文末规则回填。

## 第②步 · 元数据查询（DMV；全量拉回、本地过滤，禁加 WHERE）

```sql
-- 2-0 列模型（仅排障用：档案模型名查不到/怀疑连错模型时）
SELECT [CATALOG_NAME],[CUBE_NAME],[CUBE_TYPE],[CUBE_SOURCE]
FROM $SYSTEM.MDSCHEMA_CUBES        -- CUBE_SOURCE=1 才是真模型

-- 2-1 字段底册·表级（两行：F01 / F02；DEFAULT_HIERARCHY 供枚举探针用）
SELECT [CATALOG_NAME],[CUBE_NAME],[DIMENSION_UNIQUE_NAME],[DIMENSION_NAME],
       [DIMENSION_CARDINALITY],[DEFAULT_HIERARCHY]
FROM $SYSTEM.MDSCHEMA_DIMENSIONS

-- 2-2 字段底册·列级（每列一行 = 两表全部字段都在这里；本模型仅两表，全量拉很小）
SELECT [CATALOG_NAME],[CUBE_NAME],[DIMENSION_UNIQUE_NAME],[HIERARCHY_UNIQUE_NAME],
       [HIERARCHY_NAME]
FROM $SYSTEM.MDSCHEMA_HIERARCHIES

-- 2-3 度量底册（= 已建 measures；EXPRESSION 非空=计算度量；__Default measure 跳过）
SELECT [MEASURE_NAME],[MEASURE_UNIQUE_NAME],[MEASURE_AGGREGATOR],
       [MEASUREGROUP_NAME],[DATA_TYPE],[DESCRIPTION],[EXPRESSION]
FROM $SYSTEM.MDSCHEMA_MEASURES

-- 2-4 度量组×维度关系（缺维预检：某度量组不含某维，按该维拆必空/报错）
SELECT [MEASUREGROUP_NAME],[DIMENSION_UNIQUE_NAME]
FROM $SYSTEM.MDSCHEMA_MEASUREGROUP_DIMENSIONS
```

## 第③步 · 成员枚举与模糊匹配（DAX 先查 / MDX 兜底）

主路径 DAX（查询时动态匹配，品牌/品类再冒出新变体也不用改规则）：

```dax
-- 3b-0 DAX 关键词过滤（主路径：CONTAINSSTRING 不分大小写，与逐个枚举+本地子串匹配等价）
EVALUATE FILTER(VALUES('表'[列]), CONTAINSSTRING('表'[列], "关键词"))
```

兜底 MDX（仅当 DAX 报错/通道不可用时；拉回本地子串匹配，不分大小写）：

```sql
-- 3b-1 全量枚举（MDX 兜底主选）
SELECT [维度].[层级].MEMBERS ON 0 FROM [模型]

-- 3b-2 探针（大字段先抽 3 个成员，确认层级可用、看值形态）
SELECT SUBSET([维度].[层级].ALLMEMBERS, 0, 3) ON 0 FROM [模型]

-- 3b-3 服务端模糊（未实测，失败即退回 3b-1；InStr 区分大小写，须 LCase 包裹）
SELECT FILTER([维度].[层级].ALLMEMBERS,
       InStr(LCase([维度].[层级].CURRENTMEMBER.NAME), LCase("关键词")) > 0)
ON 0 FROM [模型]
```

填完形态示例（模型名以档案/2-0 回执为准）：

```dax
EVALUATE FILTER(VALUES('F01 线上示例表'[品牌]), CONTAINSSTRING('F01 线上示例表'[品牌], "BrandA"))
```

```sql
SELECT [F01 线上示例表].[品牌].[品牌].MEMBERS ON 0 FROM [模型名]
```

## 出口 · 组句执行（DAX 先查、MDX 兜底；结果随附语句）

执行顺序：**先组 DAX 执行** → 仅当 DAX 报错/通道不可用/回执异常，才改组同口径 MDX 重查，并注明兜底原因。数据查询 DAX 骨架（过滤一律 CONTAINSSTRING，禁精确等值）：

```dax
-- 单值
EVALUATE ROW("指标名", [度量])

-- 榜单 TopN / 按维度拆分 / 明细（拆分列可多列；外包 TOPN(n, …) 即得榜单）
EVALUATE SUMMARIZECOLUMNS('表'[拆分列],
    FILTER(VALUES('表'[过滤列]), CONTAINSSTRING('表'[过滤列], "关键词")),
    "指标名", [度量])
```

呈现纪律：**输出结果时一并输出实际执行的查询语句原文**——DAX 成功附 DAX；兜底走了 MDX 附 MDX 并注明 DAX 未成功的原因。

## 占位符回填规则

- `[模型]` ← 档案模型名（拿 2-0 回执核对过）
- `[维度].[层级]` ← 2-1/2-2 回执的 DIMENSION_UNIQUE_NAME / HIERARCHY_UNIQUE_NAME **原文复制，禁手打**
- `'表'[列]` ← 2-1/2-2 回执的表名/列名**原文复制，禁手打**（表名含空格/中文时整体放进单引号）
- `[度量]` ← 2-3 回执的度量（DAX 写 `[MEASURE_NAME]`；MDX 用 MEASURE_UNIQUE_NAME 原文复制，禁手打）
- `"关键词"` = 用户问句原词（BrandA 就填 BrandA；别名只在零命中重试时用）
